# Grand Slam Cards

A simple Flutter ordering app for a sports card store. All the app code is in `lib/main.dart`.

- 4 items with names and prices (checkboxes)
- Card sleeves switch with a message that only shows when it's on
- Total price that updates as you pick items
- Place Order button that shows a dialog
- New UI element: `Divider`

## Run
```
flutter pub get
flutter run
```
